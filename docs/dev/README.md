# Developer Notes

The `docs/dev/` folder contains notes for developers.

## Creating New Developer Notes Workflow

1. Create a new .md file in the `docs/dev/`.
2. Add to the list with a link to the file along with a description. For example, `\[evaluation\]\(./EVALUATION.md\): instructions for how to run evaluation scripts`
